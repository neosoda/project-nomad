# À propos de Project N.O.M.A.D.

Project N.O.M.A.D. est une plateforme auto-hébergée, conçue pour rendre la connaissance et les outils essentiels disponibles hors ligne.

## Principes

- **Hors ligne d'abord** : fonctionnement local prioritaire.
- **Simplicité d'exploitation** : installation et gestion centralisées.
- **Contrôle utilisateur** : vos données restent sur votre matériel.

## Composants

Le Command Center orchestre des services conteneurisés (Docker) : bibliothèque d'information, éducation, cartes, IA locale et outils utilitaires.

## Objectif

Fournir une base robuste et maintenable pour rester opérationnel en environnement déconnecté ou à connectivité limitée.
